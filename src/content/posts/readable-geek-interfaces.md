# 技术感不等于噪音

很多所谓极客风主题，实际问题是把所有元素都做成重点。结果就是：

- 标题像按钮
- 按钮像装饰
- 装饰比内容更抢眼

## 这次视觉上的收束

我选择保留明确的网格、状态标签和模块边界，但减少无意义的炫技元素，比如：

- 巨大的霓虹光晕
- 到处都是发光渐变
- 过重的玻璃拟态

## 读者真正能感知到的改进

一个普通读者不会说“这里的 token 系统设计得很好”，但会直接感知到：

1. 我能不能很快找到想看的内容。
2. 我看文章时会不会被界面打断。
3. 切换到手机后页面会不会散架。
