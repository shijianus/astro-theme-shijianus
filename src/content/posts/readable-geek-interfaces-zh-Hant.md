# 技術感不等於雜訊

許多所謂的極客風主題，實際問題在於把所有元素都當成重點。結果就是：

- 標題像按鈕
- 按鈕像裝飾
- 裝飾比內容更搶眼

## 這次視覺上的收斂

我選擇保留明確的網格、狀態標籤與模組邊界，但減少無意義的炫技元素，例如：

- 巨大的霓虹光暈
- 到處都是發光漸層
- 過重的玻璃擬態

## 讀者真正能感知到的改進

一個普通讀者不會說「這裡的 token 系統設計得很好」，但會直接感知到：

1. 我能不能很快找到想看的内容。
2. 我看文章時會不會被介面打斷。
3. 切換到手機後頁面會不會散架。
