# 首頁是入口，不是倉庫

許多部落格主題會一次性地將所有功能塞入首頁，看起來功能很多，但讀者很難判斷該先閱讀什麼。

## 我對首頁的拆解方式

新的首頁分成四個區塊：

1.  頂部 Hero 與品牌語義
2.  分類入口與狀態卡
3.  文章流
4.  側邊欄的作者與索引功能

## 為什麼這樣更耐用

因為未來增加新功能時，只需要判斷它屬於哪一個層級，而不是再臨時找地方塞入。

## 對未來 API 的幫助

當首頁層級穩定之後，即使未來接入：

-   熱門文章
-   瀏覽統計
-   即時狀態

這些資料也只是在既有位置替換內容，而不會破壞整體視覺秩序。
