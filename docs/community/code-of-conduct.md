# EpoCanvas 社群公約

<div class="article-aside">
  <p><span class="badge badge-primary">COMMUNITY-001</span> <span class="badge badge-success">全站適用</span> <span class="badge badge-warning">公開版本</span></p>
  <p>本公約適用於 EpoCanvas 的文章評論、回覆、帳號互動、社群交流與由本站管理的其他公開討論空間。它是社群共同遵守的行為底線，不是任何個人的私人意見。</p>
</div>

> [!IMPORTANT]
> 這份公約與法律、服務供應商的強制要求及站點安全措施同時生效。若不同規則發生衝突，站方會優先處理人身安全、兒童安全、帳號安全與法律合規風險。

## 1. 我們希望建立什麼樣的社群

EpoCanvas 鼓勵對前端工程、系統架構、內容創作、設計思考與長期學習進行坦率而有根據的交流。不同觀點可以被挑戰，但參與討論的人不應因此被羞辱、威脅或排斥。

社群的基本期待是：

- 先討論觀點、證據與實作，再評論對方的立場；
- 承認不確定性，清楚區分事實、推測、個人經驗與未驗證的建議；
- 尊重不同語言、地區、性別、性取向、身心狀況、宗教、年齡、技術背景與生活經驗；
- 讓新手可以提問，也讓有經驗的讀者可以指出錯誤而不必承擔人身攻擊；
- 在引用、轉載、貼圖、程式碼與第三方資料時保留來源與必要授權資訊；
- 遇到爭議時停下來確認語意，必要時使用報告與申訴流程，而不是動員圍攻。

## 2. 可接受的行為

以下行為通常屬於良性參與：

1. 對文章提出具體補充、反例、測試結果或可重現的錯誤報告。
2. 在同意與不打擾的前提下進行延伸討論、引用原文或回覆其他讀者。
3. 使用清楚、不誤導的暱稱與個人資料；必要時可選擇保持合理的匿名程度。
4. 在發現錯誤後主動更正，並尊重他人修改或刪除自己留言的權利。
5. 使用無障礙友善的文字描述，避免只依賴圖片、顏色或裝飾符號傳遞關鍵資訊。

## 3. 不被接受的行為

站方可能對以下行為採取隱藏、標記、刪除、限制互動、停權或其他必要措施：

- 騷擾、霸凌、歧視、仇恨言論、跟蹤、威脅或煽動他人攻擊；
- 公開或散播他人的私人資料、帳號憑證、精確位置、聯絡方式或其他未經同意的個人資訊；
- 冒充站長、管理員、其他讀者、組織或服務供應商，或使用誤導性身分取得信任；
- 重複灌水、無關廣告、惡意引流、機器人貼文、刷量、刷讚或協同操弄討論；
- 發布惡意程式碼、釣魚連結、木馬、未揭露的追蹤器、欺詐內容或蓄意破壞站點的指引；
- 以大量檢舉、集體圍攻、公開羞辱或報復手段壓制正常討論；
- 以規避限流、停權、審核或身份驗證為目的而建立或使用其他帳號；
- 侵犯著作權、商標、肖像權、隱私權或其他第三方權利的內容；
- 任何明顯違法、危害人身安全或會使其他使用者暴露於不當風險的內容。

技術辯論本身不是違規。即使某個說法尖銳，只要它針對可檢驗的觀點而非攻擊個人，通常會先以提醒與引導為主；但「只是開玩笑」不會自動成為騷擾或歧視的豁免理由。

## 4. 站方如何執行公約

站方會依照內容的嚴重程度、是否重複、造成的實際風險、是否配合修正，以及帳號是否試圖規避處置來決定措施。可能的處置包括：

1. 私下提醒、要求補充來源或修改表述；
2. 對留言進行標記、降低可見性、暫停互動或移除；
3. 暫時限制留言、回覆、Reaction、Boost 或帳號功能；
4. 對持續或嚴重違規的帳號停權；
5. 在涉及安全、詐欺、惡意程式或法律義務時，保留必要的審計資料並採取額外措施。

處置不必然依序進行。若存在即時風險，站方可以先限制內容或帳號，再於安全可行時補充說明。公開評論的狀態目前包含 `published`、`pinned`、`flagged` 與 `deleted`；狀態名稱是系統資料狀態，不代表每一次標記都等同於對作者的道德判定。

## 5. 報告與申訴

若你看見違反本公約的內容，請使用[檢舉與申訴說明](/community/reporting-and-appeals/)。報告時請提供文章網址、留言或帳號識別資訊、問題類型、必要的時間點與可安全公開的證據；請不要在公開留言中貼出受害者的私人資料或完整憑證。

如果你認為自己的內容或帳號被誤處置，也可以依同一頁的申訴方式補充背景與證據。申訴會重新檢視事實與規則適用情況，但不保證原處置必然撤銷，也不會因申訴而自動恢復已刪除資料。

## 6. 公約的維護

本公約會隨社群功能、法律要求與安全風險變化而更新。更新會記錄在版本控制中；重大變更應在頁面更新日期與變更摘要中說明。若某一條款被認定無法執行，其餘條款仍然有效。

若問題同時涉及帳號、會話或憑證，請改依[帳號與會話安全說明](/community/account-and-session/)及[安全問題通報規範](/community/security-disclosure/)處理，不要在公開討論中貼出敏感資料。
