## 2. 閱讀與適用順序

如果你只是想參與討論，先閱讀《社群公約》與《評論與審核規範》即可。若要發表涉及個人資料、引用或轉載的內容，還應閱讀《隱私與資料使用說明》及《內容授權與版權說明》。若你需要使用本站的帳號、評論或讚賞功能，則也適用《使用條款》。

這些政策彼此互補，但不會把徽章、顯示名稱或一次成功的 API 回應變成安全權限。權限以當下的會話驗證、服務端規則與站務處置為準；身份徽章只提供社群層面的辨識與成就資訊。

## 3. 政策與實作的關係

政策頁會盡量只描述目前可以由程式碼、測試或公開服務行為核對的內容。若某項規則仍在遷移、前端與後端存在差異，頁面會明確標示「已知差異」或「待統一」，不把規劃中的功能寫成已經提供的承諾。

對評論、Reaction、帳號與支付而言，服務端驗證優先於瀏覽器畫面上的提示。對內容授權而言，文章中的第三方程式碼、圖片、字型、商標或引用資料可能受其原始權利人條款約束，不能僅因它出現在本站就推定屬於本站授權。

## 4. 政策更新與聯絡方式

政策會因功能變更、安全風險、第三方服務或適用法律而更新。每一頁都應標示最後更新日期；重大變更會在正文中補充影響範圍。若你無法判斷某項規則是否適用，請先以[檢舉與申訴說明](/community/reporting-and-appeals/)中的方式聯絡站方，不要在公開留言中貼出敏感資料。

一般政策、隱私請求、內容權利或安全事件可寄至 [contact@epocanvas.com](mailto:contact@epocanvas.com)。請在信件中只提供定位與處理案件所需的最少資訊。
