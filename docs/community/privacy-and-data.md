# EpoCanvas 隱私與資料使用說明

<div class="article-aside">
  <p><span class="badge badge-primary">COMMUNITY-003</span> <span class="badge badge-success">資料透明度</span> <span class="badge badge-warning">持續更新</span></p>
  <p>本頁說明本站目前為提供評論、登入、反濫用、讚賞與站務維護而處理的資料。它不是對任何司法管轄區的法律意見；若你有特定法域的權利請求，請提供必要背景以便站方處理。</p>

> [!IMPORTANT]
> 本站不應接收或保存支付卡號、卡片安全碼等完整支付憑證。Stripe 結帳由 Stripe 的支付介面處理；請勿在評論、寄語或聯絡信件中主動提交卡號與密碼。

## 1. 資料來源與處理目的

本站可能從以下來源取得資料：

| 來源 | 可能資料 | 用途 |
| :--- | :--- | :--- |
| 評論或回覆表單 | 內容、暱稱、電子郵件、頭像、網站、引用與文章識別資訊 | 發表、顯示、編輯、刪除與通知 |
| 請求與安全標頭 | IP、Cloudflare 國家代碼、User-Agent、時間與請求結果 | 限流、重複提交攔截、地區顯示、安全審計與故障排查 |
| 登入與帳號中心 | 電子郵件、名稱、頭像、網站、身份提供者、外部識別碼、簡介、時區、地區與會話資料 | 建立會話、同步讀者身份、提供帳號功能與權限判定 |
| Reaction 與互動 | Emoji、反應摘要、操作者關聯、按讚計數、留言狀態 | 顯示互動結果、防止重複反應與產生通知 |
| 讚賞流程 | 金額、幣種、稱呼、寄語、國家、IP、付款狀態與時間 | 顯示讚賞記錄、核對交易、處理通知與安全審計 |

上述欄位不一定在每一次請求中都有值；訪客、登入讀者、管理員與支付流程的資料欄位也不完全相同。

## 2. 公開顯示與管理存取

評論公開介面會依身份與設定做資料最小化：

- 會顯示留言內容、公開暱稱、頭像、角色徽章、時間、回覆關係、Reaction 摘要，以及依規則顯示的國家/地區資訊。
- 不向一般讀者公開其他人的電子郵件、原始 IP、User-Agent、會話令牌或反應使用者對照表。
- 訪客的國家/地區依目前社群規則公開；登入讀者可選擇隱藏自己的地區。
- 管理員在有效的管理驗證下可以查看較完整的審計欄位，以處理濫用、申訴、帳號安全與法律要求。
- 讚賞公開記錄會依站點呈現規則顯示必要的稱呼、寄語、金額/幣種、通道與時間；支付與安全欄位不應直接暴露給一般讀者。

公開顯示不代表資料失去所有權，也不代表站方會把資料提供給任何第三方。站方會依本頁、社群規範與適用法律處理存取要求。

## 3. 第三方服務與資料流向

本站使用 Cloudflare Pages/Workers/D1 等基礎設施提供頁面、邊緣 API 與資料儲存；Stripe 處理國際結帳；Epomail 可作為登入身份提供者；Telegram Bot 可接收站務通知、評論通知或讚賞通知。這些服務各自受其服務條款與隱私政策約束。

站方會把必要的事件資料傳送給對應服務以完成請求或通知。例如評論通知可能包含文章識別、作者名稱、留言、IP/地區與事件編號；讚賞通知可能包含交易與寄語摘要。請不要把不必要的敏感資料寫入公開留言或寄語。

## 4. 保留、刪除與更正

目前程式碼沒有提供一個統一、公開承諾的資料保留期限，因此本站不在本頁虛構固定天數。資料可能因提供功能、處理申訴、預防濫用、財務核對、安全審計或法律義務而保留；實際期限取決於資料類型、儲存服務與事件狀態。

你可以提出以下要求：

1. 查詢與自己帳號或留言相關的資料範圍；
2. 更正不準確的名稱、頭像、網站、地區顯示設定或留言內容；
3. 申請刪除可刪除的留言、帳號資料或不再需要的公開資訊；
4. 針對必要保留的資料，要求說明保留目的與限制公開的範圍。

為防止他人冒領，站方可能要求透過原有帳號、有效會話、留言所有權或其他合理方式核驗身分。刪除請求不一定能抹除已經進入備份、審計、法律紀錄或第三方支付/通知系統的所有副本；若無法完全刪除，站方會說明原因與可採取的最小化措施。

## 5. 安全與使用者責任

站方會以權限分離、公開資料遮蔽、會話驗證與服務商安全機制降低風險，但任何網路傳輸與儲存都不能承諾絕對安全。請使用不重複的密碼、不要分享會話令牌，不要把支付卡號、身份證件、精確住址或其他不必要的敏感資料貼到公開欄位。

如果你發現帳號被冒用、令牌外洩、釣魚連結、私人資料外洩或其他安全問題，請依[檢舉與申訴說明](/community/reporting-and-appeals/)聯絡站方；涉及即時危險時，請先聯絡當地緊急服務。

## 6. 聯絡與版本

資料查詢、更正、刪除與隱私疑問可寄至 [contact@epocanvas.com](mailto:contact@epocanvas.com)，並在主旨中標示「隱私請求」。請只提供處理案件所需的最少資訊，不要在第一封信中附上完整密碼、支付卡資料或未遮蔽的身份文件。

本說明會隨資料流、第三方服務與法律要求更新。最後更新：2026-10-18。
