# EpoCanvas 翻譯與多語言維護政策

<div class="article-aside">
  <p><span class="badge badge-primary">COMMUNITY-013</span> <span class="badge badge-success">語言治理</span> <span class="badge badge-warning">本輪暫不翻譯</span></p>
  <p>本頁定義官方政策、工程標準與普通文章在多語言維護上的優先順序。當前這一輪文件工作先以正體中文建立權威基線，不把未審閱的其他語言版本視為同步完成。</p>
</div>

> [!IMPORTANT]
> 語言切換、文字轉換或頁面存在多個翻譯版本，不等於每個版本都具有相同的政策權威。若翻譯內容與正體中文官方基線或服務端實作衝突，應先依正體中文基線與實際服務端驗證處理，並回報差異。

## 1. 適用範圍與權威順序

本政策適用於 `docs/community/`、`docs/standards/`、`docs/roadmap.md`、`docs/operations/` 及 `src/content/posts/` 中的多語言內容。

目前的官方維護順序是：

1. 正體中文的政策與工程規範是本輪治理工作的編輯基線；
2. 其他語言版本只有在完成人工核對、連結檢查與必要測試後，才可標記為官方同步版本；
3. 普通文章的翻譯屬於內容版本，不會自動升格為政策或工程契約；
4. 介面上的 OpenCC 轉換、瀏覽器翻譯或機器翻譯結果，是閱讀輔助，不是已審閱的法律、權限或安全文字。

網站目前仍可能存在 `zh-CN` 預設介面與不同語言文章。這是產品語言設定與文件治理的兩個不同問題；不要因為介面可以切換文字，就宣稱所有官方文件已完成 i18n。

## 2. 翻譯狀態

文件或版本記錄應使用能讓讀者理解的狀態，而不是只依檔名猜測：

| 狀態 | 意義 | 可引用程度 |
| :--- | :--- | :--- |
| `SOURCE` | 正體中文或指定源語言的目前基線 | 可作為該文件的主要規則來源 |
| `TRANSLATED-REVIEWED` | 已由人工依源文逐段核對，並完成連結/術語檢查 | 可作為該語言的官方閱讀版本 |
| `COMMUNITY-DRAFT` | 社群提供的翻譯草稿，尚未完成官方審閱 | 不應單獨用於推導權限或政策結論 |
| `MACHINE-AIDED` | 使用機器或工具協助產生，仍需要人工審閱 | 只能作為閱讀輔助 |
| `STALE` | 源文已變更，翻譯未跟上 | 應回到源文，並標記待同步 |

`lang`、`i18nKey`、`isAiGenerated` 與 `aiTranslatedFrom` 等欄位可以協助追蹤，但欄位存在本身不代表翻譯品質或政策等價已經完成。

## 3. 官方翻譯的最低要求

正式同步其他語言版本前，至少需要：

- 對照源文的標題、適用範圍、警告、例外、表格、程式碼與連結；
- 保留 API 路由、角色名稱、狀態碼、版本號、檔案路徑與命令的可執行拼法；
- 不把「可能」「建議」「已知差異」翻成確定承諾，也不刪除 `PROPOSED`、`KNOWN-GAP` 或安全警告；
- 檢查術語在社群公約、評論、隱私、身份與工程規範之間一致；
- 在源文更新後重新檢查翻譯，並留下版本或提交的追溯資訊；
- 若翻譯者補充了源文沒有的法律、權限或安全結論，先回到源文提出修訂，不要只在翻譯頁新增契約。

安全事件、漏洞、個人資料、支付與帳號權限的翻譯，不得使用公開機器翻譯結果直接作為唯一告知內容。

## 4. 衝突、落後與撤回

如果翻譯頁與正體中文源文衝突：

1. 先在翻譯頁標記 `STALE` 或補上待同步提示；
2. 以正體中文源文與服務端實際驗證結果處理當下權限與安全決策；
3. 建立可定位的修訂項目，列出受影響的章節、語言與讀者；
4. 完成逐段核對、建置與必要的連結/瀏覽器檢查後，才移除落後標記。

若翻譯包含錯誤、未授權內容或敏感資料，維護者可以暫時下線或回退該版本。已經被讀者快取、引用、備份或第三方服務處理的副本，不一定能立即全部撤回。

## 5. 本輪工作與後續計畫

本輪只撰寫與完善正體中文的官方文件，不同步重寫簡體中文、英文、德文、西文或法文版本。這不是對其他語言讀者的拒絕，而是先建立單一、可核驗的規則基線，避免在權威內容仍變動時擴大語義漂移。

日後啟動其他語言的同步工作時，應先確認：源文已穩定、規則已由程式碼/測試核對、翻譯範圍與審閱者明確、版本差異可追溯，以及安全與法律文字有人工覆核。

翻譯建議可依[貢獻與官方文件編輯規範](/community/contributing-and-editorial/)提交。涉及政策錯誤、個資或安全問題時，請改用[檢舉與申訴說明](/community/reporting-and-appeals/)或[安全問題通報規範](/community/security-disclosure/)的私下管道。
